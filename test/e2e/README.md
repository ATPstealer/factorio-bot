# E2E-тесты

Требуют запущенной игры (`scripts/run.sh` или `scripts/newmap.sh`). Запуск — `scripts/test.sh`: перед e2e всегда `go vet` и юнит-тесты (`go test ./internal/...`).

## Наборы

| Набор | Запуск | Время | Назначение |
|---|---|---|---|
| База | `scripts/test.sh` | ~10–15 мин | функции, без которых ничего не работает |
| Прохождение | `SET=game scripts/test.sh` | ~2 ч с нуля | шаги игры по порядку на одной карте |
| Прочие | `SET=extra scripts/test.sh` | ~15 мин | старые сценарии вне прохождения |
| Всё | `SET=all scripts/test.sh` | ~2.5 ч | финальная регрессия стадии |

Один тест по имени (шаблон `-run`) на текущей карте: `scripts/test.sh Build`.

### 1. База — `TestBase_*`

| Тест | Что проверяет |
|---|---|
| `Config`, `Game` | окружение: игра, мод, клиент, настройки |
| `Walk` | дойти до точки |
| `Mine` | срубить дерево |
| `OnlyCharted` | честность: не видеть неоткрытое |
| `WorldMatchesGame` | модель карты совпадает с игрой |
| `Craft` | ручной крафт |
| `PathAroundLake` | обойти воду |
| `Guards` | выйти из меню и карты |
| `DrillOneOreTile` | поставить, повернуть, поднять бур |
| `FurnaceHugsTree` | поставить вплотную к дереву, срубить, не задев постройку |
| `DropAndCollectInOrder` | выложить предметы на землю и собрать |
| `Unstuck` | выбраться из кольца своих построек |
| `SnapshotMatchesGame`, `AvailabilityMatchesForce`, `RocketPartPlan` | справочник прототипов и калькулятор |
| `Layout` | кластеры красной науки «на бумаге» по живой карте (`bin/bot clusters`): места, внутренности, логистика — без ошибок проверки |
| `Build` | построить раскладку: материалы, слои, направления, топливо |
| `Belt` | лента-змейка (10 изгибов): предмет доезжает до конца |
| `Pipe` | труба от помпы через «стену» подземной парой: вода доходит до конца |

### 2. Прохождение игры — `TestGame<стадия>_<пункт>_*`

Шаги идут по порядку на одной карте с общим состоянием бота (`run/state-game.json`): стадия 10 — прохождение кластерами по этапам `game-stages.md`, лимит шага — 2× лимита этапа. После каждого шага `test.sh` сохраняет снимок `game-10.N` с описанием (`scripts/snapshot.sh list`).

| Шаг | Лимит | Что |
|---|---|---|
| `10_0_Stage0` | 60 мин | этап 0 с новой карты: старт руками, станция и лаборатории, изучены электробуры |
| `10_1_Stage1` | 60 мин | этап 1: `logistics`, добыча угля/железа/меди, плавка (уголь отводом, буферы по предмету на входящих лентах), станция на угле с ленты; монитор — `run/clusters.txt` |
| `10_2_Stage2` | 120 мин | этап 2: шестерни и красная наука — свои кластеры (пластины с этапа 1), лаборатории, рост станции и угля в запасе; изучено на красной для ракеты |

Новый этап — шаг `TestGame10_N_…`, номер в `steps` и описание снимка в `note` в `scripts/test.sh`, цели — `exec.StageTargets`.

Запуск:

- `SET=game NEW_MAP=1 scripts/test.sh` — все шаги с нуля; `SEED=927139741` — хорошая карта для быстрого теста начала;
- `SET=game GAME_FROM=10.1 scripts/test.sh` — с шага 10.1 (грузит снимок предыдущего шага `game-10.0`);
- `scripts/test.sh Game10_2` — один шаг на текущей карте (продолжить с места); `SNAP=game-10.1 scripts/test.sh Game10_2` — со снимка.

### 3. Прочие сценарии — `TestExtra_*`

| Тест | Время | Что делает |
|---|---|---|
| `FurnaceScenario` | ~1 мин | камень → печь → уголь и руда → пластины |
| `SnailMaze` | 2–15 мин | выйти из «улитки» печей |
| `SmeltingLine` | ~10 мин | линия из 5 печей с нуля + восстановление после удаления |

## Карта и снимки

- По умолчанию — текущая карта; игра перезапускается на ней же, только если не запущена или изменился мод (хеш `run/mod.hash`).
- `NEW_MAP=1` — новая случайная карта, `SEED=…` — конкретная, `SNAP=имя` — со снимка.
- Снимки: `scripts/snapshot.sh save ИМЯ "описание"`, `load ИМЯ`, `list`.

## Когда что гонять

- Правка одной способности — её тест: `scripts/test.sh Build`.
- Перед коммитом — база: `scripts/test.sh`.
- Правка стратегии или шага прохождения — этот шаг со снимка предыдущего: `SET=game GAME_FROM=7.N`.
- Конец стадии — `SET=all scripts/test.sh` (база, прочие, прохождение с нуля на новой карте).
