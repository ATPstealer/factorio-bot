# E2E-тесты

Требуют запущенной игры (`scripts/run.sh` или `scripts/newmap.sh`). Запуск — `scripts/test.sh`: перед e2e всегда `go vet` и юнит-тесты (`go test ./internal/...`).

## Наборы

| Набор | Запуск | Время | Назначение |
|---|---|---|---|
| База | `scripts/test.sh` | ~10–15 мин | функции, без которых ничего не работает |
| Прохождение | `SET=game scripts/test.sh` | ~2 ч с нуля | шаги игры по порядку на одной карте |
| Прочие | `SET=extra scripts/test.sh` | ~15 мин | старые сценарии вне прохождения |
| Всё | `SET=all scripts/test.sh` | ~2.5 ч | финальная регрессия стадии |

Один тест по имени (шаблон `-run`) на текущей карте: `scripts/test.sh Build`.

### 1. База — `TestBase_*`

| Тест | Что проверяет |
|---|---|
| `Config`, `Game` | окружение: игра, мод, клиент, настройки |
| `Walk` | дойти до точки |
| `Mine` | срубить дерево |
| `OnlyCharted` | честность: не видеть неоткрытое |
| `WorldMatchesGame` | модель карты совпадает с игрой |
| `Craft` | ручной крафт |
| `PathAroundLake` | обойти воду |
| `Guards` | выйти из меню и карты |
| `DrillOneOreTile` | поставить, повернуть, поднять бур |
| `FurnaceHugsTree` | поставить вплотную к дереву, срубить, не задев постройку |
| `DropAndCollectInOrder` | выложить предметы на землю и собрать |
| `Unstuck` | выбраться из кольца своих построек |
| `SnapshotMatchesGame`, `AvailabilityMatchesForce`, `RocketPartPlan` | справочник прототипов и калькулятор |
| `Layout` | раскладка «на бумаге» по живой карте |
| `Build` | построить раскладку: материалы, слои, направления, топливо |
| `Belt` | лента-змейка (10 изгибов): предмет доезжает до конца |
| `Pipe` | труба от помпы через «стену» подземной парой: вода доходит до конца |

### 2. Прохождение игры — `TestGame<стадия>_<пункт>_*`

Шаги идут по порядку на одной карте с общим состоянием бота (`run/state-game.json`). Номер шага = пункт плана (`plan.md`): `TestGame7_6_Factory` — стадия 7, пункт 6. После каждого шага `test.sh` сохраняет снимок `game-7.6` с описанием (`scripts/snapshot.sh list`).

| Шаг | Время | Что делает |
|---|---|---|
| `7_0_Start` | ~25 мин | новая карта: 50 дерева, 200 камня с камней, точки на бурах (уголь парами, бур → печь, камень → сундук) |
| `7_2_Power` | ~10 мин | станция у воды (бойлер + сундук-кормушка), лаборатории, столбы — одна сеть |
| `7_3_Research` | ~5 мин | изучить `automation`: наука руками, запуск через окно технологий |
| `7_4_Recipe` | ~1 мин | сборщик: поставить и задать рецепт через окно |
| `7_5_ElectricMining` | ~5 мин | изучить электробуры |
| `7_6_Factory` | ~20 мин | фабрика красной науки: электробуры, сборщики, лаборатории, ленты |
| `7_7_PowerOutage` | ~5 мин | «пропало питание»: бот замечает, находит причину, чинит (заправка, расширение станции) |
| `7_8_RedScience` | ~30 мин | красная наука для ракеты (без оружия) со сборщиков — критерий стадии 7 |
| `8_1_GreenScience` | ~40 мин | блок зелёной науки, ряды плавки, станция растёт |
| `8_2_GreenResearch` | ~30 мин | исследования на красной+зелёной до oil-gathering |
| `8_3_Steel` | ~18 мин | ряд стали: бур → печь → печь → сундук |
| `8_5_Oil` | ~60 мин+ | разведка нефти, насосы и линия столбов, нефтезавод, химзаводы: пластик и сера |
| `8_6_CoalMine` | ~20 мин | угольная шахта на электробурах с сундуками у станции |
| `8_7_OilBelt` | ~90 мин | лента пластика с нефти на базу (по ходу: склад железа, лента угля к бойлерам) |
| `8_8_BlueScience` | ~2 ч | блок синей науки (красные схемы, двигатели), синяя — лентой к лабораториям |

Дальше по стадиям — `TestGame8_1…` (зелёная наука, сталь, нефть…): номер шага в `steps` и описание снимка в `note` в `scripts/test.sh`.

Запуск:

- `SET=game scripts/test.sh` — все шаги с нуля (шаг 1 — новая карта);
- `SET=game GAME_FROM=7.7 scripts/test.sh` — с шага 7.7 (грузит снимок предыдущего шага `game-7.6`);
- `scripts/test.sh Game7_4` — один шаг на текущей карте; `SNAP=game-7.3 scripts/test.sh Game7_4` — со снимка.

### 3. Прочие сценарии — `TestExtra_*`

| Тест | Время | Что делает |
|---|---|---|
| `FurnaceScenario` | ~1 мин | камень → печь → уголь и руда → пластины |
| `SnailMaze` | 2–15 мин | выйти из «улитки» печей |
| `SmeltingLine` | ~10 мин | линия из 5 печей с нуля + восстановление после удаления |

## Карта и снимки

- По умолчанию — текущая карта; игра перезапускается на ней же, только если не запущена или изменился мод (хеш `run/mod.hash`).
- `NEW_MAP=1` — новая случайная карта, `SEED=…` — конкретная, `SNAP=имя` — со снимка.
- Снимки: `scripts/snapshot.sh save ИМЯ "описание"`, `load ИМЯ`, `list`.

## Когда что гонять

- Правка одной способности — её тест: `scripts/test.sh Build`.
- Перед коммитом — база: `scripts/test.sh`.
- Правка стратегии или шага прохождения — этот шаг со снимка предыдущего: `SET=game GAME_FROM=7.N`.
- Конец стадии — `SET=all scripts/test.sh` (база, прочие, прохождение с нуля на новой карте).
