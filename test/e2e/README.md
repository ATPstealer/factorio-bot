# E2E-тесты

Требуют запущенной игры (`scripts/run.sh` или `scripts/newmap.sh`). Запуск — `scripts/test.sh`: перед e2e всегда `go vet` и юнит-тесты (`go test ./internal/...`).

## Наборы

| Набор | Запуск | Время | Назначение |
|---|---|---|---|
| База | `scripts/test.sh` | ~3 мин | функции, без которых ничего не работает |
| Прочие | `SET=extra scripts/test.sh` | ~1 мин | сценарии длиннее базы |
| Всё | `SET=all scripts/test.sh` | ~5 мин | всё |

Один тест по имени (шаблон `-run`) на текущей карте: `scripts/test.sh Walk`.

### База — `TestBase_*`, по файлам

| Файл | Тесты | Что проверяют |
|---|---|---|
| `env_test.go` | `Config`, `Game` | окружение: настройки, мод, сервер, карта, клиент |
| `interface_test.go` | `Guards`, `InventoryWindow`, `PickFromInventory`, `StartResearch`, `SetRecipe`, `SetFilter` | меню и карта не мешают; окно инвентаря; взять предмет из инвентаря в руку; запустить исследование; сборщик: поставить, задать и сменить рецепт; фильтр инсертера |
| `world_test.go` | `OnlyCharted`, `WorldMatchesGame` | бот видит только открытое; модель карты совпадает с игрой |
| `walk_test.go` | `Walk`, `PathAroundLake`, `Unstuck`, `Explore` | до точки; в обход воды; из кольца своих построек; разведка (открыть ещё 10 чанков) |
| `hands_test.go` | `Mine`, `Craft`, `DrillOneOreTile`, `FurnaceHugsTree`, `PlaceNextToSelf`, `PlaceAmongBelts` | срубить дерево; крафт; поставить, повернуть, поднять; поставить у дерева, срубить, не задев; поставить на свою клетку и вплотную; поставить в квадрат 12×12, наполовину в случайных лентах (`SEED_BELTS=…` — повторить) |
| `knowledge_test.go` | `SnapshotMatchesGame`, `AvailabilityMatchesForce`, `RocketPartPlan` | справочник прототипов; калькулятор |

Общие помощники — `helpers_test.go`.

### Прочие — `TestExtra_*`

| Тест | Время | Что делает |
|---|---|---|
| `FurnaceScenario` | ~1 мин | камень → печь → уголь и руда → пластины |

Предметы для теста набирает `have` (сырьё — руками, остальное — крафт); нужны пластины, а их нет — тест пропускается.

## Карта и снимки

- По умолчанию — текущая карта; игра перезапускается на ней же, только если не запущена или изменился мод (хеш `run/mod.hash`).
- `NEW_MAP=1` — новая случайная карта, `SEED=…` — конкретная (`SEED=927139741` — хорошая для быстрого начала), `SNAP=имя` — со снимка, `SAVE_AS=имя` — снимок после зелёного прогона.
- Снимки: `scripts/snapshot.sh save ИМЯ "описание"`, `load ИМЯ`, `list`.

## Когда что гонять

- Правка одной способности — её тест: `scripts/test.sh Walk`.
- Перед коммитом — база: `scripts/test.sh`.
