# Factorio Bot — план

Цель: бот с нуля строит базу и запускает ракету (Factorio 2.0.77, base, без Space Age) без единого клика игрока, на любой случайной карте (утёсы как в обычной игре, кусак нет).

Подробности сделанного (стадии 1–8 по пунктам, решения по ходу) — в истории git (`a6db313:plan.md`); здесь — что умеет бот и что дальше.

---

## 0. Ключевые решения

| Вопрос | Решение |
|---|---|
| Версия | Factorio 2.0.77, только `base`. «Улететь» = запуск ракеты. |
| Честность | Действия — только ввод мыши/клавиатуры (XTEST) в окно клиента. Мод `botbridge` только читает, и только видимое игроку: открытые (charted) чанки, свои инвентарь/исследования, справочник прототипов. Исключение — `Say` (текст в консоль). |
| Запуск | Headless-сервер (RCON) + клиент в Xephyr `:1`; ввод бота только туда. |
| Карты | Тесты — на случайных картах; тесты не опираются на места/ресурсы, бот разведывает. Хорошая карта для быстрого теста начала — сид **927139741** (`SEED=927139741 scripts/newmap.sh`): этап 0 — 31 мин, всё нужное рядом (железо, уголь, медь, камень, озеро). |
| База | Кластерами (стадия 9); после нулевого этапа руками ничего не возит — только строит. |
| Поздняя стройка | Чертежи через GUI → призраки → строительные роботы. |

## 1. Архитектура

```
Factorio server ── mod botbridge (read-only, RCON) ──┐      Xephyr :1: клиент ◄── XTEST
                                                      ▼                              ▲
bot (Go): rcon → bridge │ input, camera, act (руки, GUI) ──────────────────────────────┘
          knowledge, calc (справочник, калькулятор) │ world (модель карты, пути)
          layout (раскладки) │ plan (HTN, цели, наблюдатель) │ exec (Runner, главный цикл)
```

Пакеты: `internal/{rcon,bridge,input,camera,act,knowledge,calc,world,layout,plan,exec}`, `cmd/bot`, `mod/botbridge`, `scripts/`, `test/e2e/` (наборы и снимки — `test/e2e/README.md`).

## 3. Дальше

### Стадия 9. Кластерная база — 🔶 план

Цель: вся база (кроме нулевого этапа) строится и растёт кластерами. Кластер — прямоугольник на карте с известными входами и выходами (шт/с, кВт); бот планирует кластеры под задачу этапа, строит, раз в минуту измеряет in/out и устраняет нехватку. После нулевого этапа ручной подвоз и перекладывание строго запрещены: уголь, руда, пластины, сера — только лентами и трубами; руками — только стройка.

**9.0. Понятия**
- Имя `<продукт>-<N>` (`coal-1`, `iron-plate-1`, `red-science-1`, `power-1`, `lab-1`, `storage-1`); прямоугольник, рецепты, `In`/`Out` (предмет/жидкость шт/с, электричество кВт), internal in/out (промежуточное внутри; internal out ≥ internal in), текущее содержимое.
- Виды: добыча (только на месторождениях; in — кВт, out — руда лентой), обработка (плавка, сборка, химия), энергия (in — уголь лентой, out — кВт), научный (`lab-N`: только in — пакеты лентой и кВт), хранение (`storage-N` — мусор бота: буры нулевого этапа, разобранное).
- Гранулярность решает бот (один кластер «всё → наука» или отдельные). Out одного кластера кормит несколько других, если хватает.
- Расчёт — `calc.Solve` × 1.2 (лучше перепроизвести), округление вверх.

**9.1. Разметка карты**
- У каждого кластера свой коридор 6 тайлов (между соседями 12): ленты, трубы, столбы, проход бота. Коридоры общие — логистика идёт и по коридору соседа (шина, общая линия столбов). Через кластер ленты и трубы не идут никогда.
- Месторождения (руда, камень, уголь, нефть) + 6 тайлов — только кластерам добычи. Вода ресурсом не считается.
- Утёсы и вода внутри кластера — только если ничего не стоит на утёсе/в воде и бот подходит к каждой постройке (проверка раскладки до стройки).
- Запас под рост out без переезда: этапы 0–4 — ×5, 5–6 (и, возможно, 7) — ×2, дальше ×1.5. Out растёт: машины лучше, модули, лента быстрее, больше машин (место — длиной в сторону роста, только на то, что не дадут апгрейды). Продукт кластера не меняется; запас кончился — кластер `N+1`.
- Магистрали — шина по коридорам с отводами; электричество — столбы по коридорам.

**9.2. Буферы на входе**
- Лента непрерывная; рядом цепочка: инсертер с фильтром с ленты → ящик 1 → … → ящик n → инсертер обратно на ленту ниже по ходу, на свою полосу. Минимум 2 ящика.
- Ёмкость — 10 минут работы кластера без подачи. Отдача быстрой не делается: одна цепочка на вход.

**9.3. Измерение и статус**
- Раз в минуту in/out каждого кластера: сначала по статусам машин (доля «работает» × номинал) и содержимому буферов; дальше — поток через контрольный тайл ленты.
- Нехватка in — проблема; out мал из-за пробки готового — норма.
- Файл статуса раз в минуту: `run/clusters.txt` (читаемый: in/out план/факт, буферы, проблемы), `run/clusters.json`.
- Картинка базы `bin/bot map -clusters -o F`: кластеры одним цветом, коридоры — другим, имена, месторождения, магистрали.

**9.4. Устранение и рост**
- Больше out кластера X: сначала нарастить кластеры, дающие ему in (по цепочке вниз до добычи и энергии), потом X.
- In пропал, руда кончилась — буры на месторождении или новый кластер добычи (разведка).

**9.5. Переход с нулевого этапа**
- Нулевой этап кончается, только когда электричество уже есть: пока `coal-1` не кормит станцию, уголь в бойлеры — руками (это ещё нулевой этап).
- Как только готовы электричество, первые электробуры и плавильные кластеры — ряды плавки на руде и угольные буры разбираются в `storage-1`.

**Решения (2026-10-19)**

- Плавка до электропечей: руда и уголь одной лентой по разным полосам (уголь из `coal-1` по шине).
- Этап 1 — ленты точка-точка по коридорам; шина — с этапа 2 (разделители после `logistics`).
- Лаборатории — рядом с кластерами науки. Ходьба дальше — не страшно; страшно застревание: коридоры и проходы важнее компактности.

**Порядок работы**

**9.6. Тесты**
- Юнит: разметка (коридоры, месторождения, запас), буфер (ёмкость), расчёт кластера по цели, правило «сначала in».
- e2e: первый кластер (`iron-plate-1` с буфером) строится, статус в файле, картинка.

### Стадия 10. Прохождение кластерами (этапы 0–6) — план в `game-stages.md`

Этапы с кластерами, лимитами времени и темпом науки — `game-stages.md` (правит пользователь): 0 старт руками, 1 электричество и плавка, 2 красная, 3 зелёная, 4 сталь и нефть, 5 синяя, 6 фиолетовая и жёлтая (до `rocket-silo`). Каждый этап — шаг прохождения `TestGame<этап>_…` (заменяют `TestGame7_*`/`TestGame8_*`), прогоны — с новой карты, снимок после каждого. Не уложился в лимит — в отчёт узкий кластер.

### Стадия 11. Строительные роботы
- `construction-robotics`, личный робопорт, модульная броня; раскладка → чертёж (импорт строки через GUI) → призраки; бот обеспечивает материалы.
- **Готово, когда:** новый кластер ставится одной операцией «разместить чертёж + материалы».

### Стадия 12. Ракета
- Кластеры `rocket-fuel`, `lds`, `processing-unit`, силос; ракетные части; запуск.
- **Готово, когда:** ракета запущена, ноль ручных действий.

### Сквозное
- **Наблюдатель** (`plan.Diagnose` → `Repair`, сделано: питание, топливо, простой лабораторий с причиной, застой исследования) → статусы кластеров (9.3); прогноз истощения месторождений; узкие места по статистике.
- **Обобщение на карты** (сделано: случайные карты, утёсы, разведка): прогоны на 3+ картах после каждой стадии; метрики — время этапов, отказы.
- **Скорость действий**: искать долгие операции по журналу (`golden-report.txt`) и сокращать.

## 4. Риски

| Риск | Что делаем |
|---|---|
| Промахи кликов / GUI | фиксированные разрешение/UI scale, подтверждение каждого шага модом, снимки при сбое |
| Ходьба застревает | A* по рамкам, пометка мест, пролом, выход с ленты, предел времени шага |
| Бот зацикливается | баны, предел шага, 8 отказов подряд — стоп, журнал причин |
| Логистика между кластерами | коридоры и шина вместо лент «через полкарты» |
| Нефть/ресурсы далеко | разведка концентрическими кругами, кластер добычи на месте, лента/труба по коридорам |
