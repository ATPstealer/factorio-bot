# Самостоятельная работа

## Порядок

1. **Тесты.** Новые и затронутые правкой — на всех картах `-0`:
   `PAR=4 scripts/bench.sh Шаблон`; затронут общий код (act, world, layout, cluster) — весь
   бенч `PAR=4 scripts/bench.sh`. Юнит-тесты — `go test ./internal/...`.
   Упал тест механики — скилл `bug-to-test` (тест не трогать, чинить бота).
2. **Только стадии планирования** — чтобы получились новые картинки, без стройки:
   `PLAN=1 scripts/stage.sh 4-10 851731946 859088572 794457638` (со снимка `<сид>-3`, стадии
   с `Plan: true` подряд: план прошлых считается построенным; снимки не сохраняются). Картинки —
   `run/stages/zones-<сид>.png` (зоны), `plan-<сид>.png` (план кластеров), `plan-green-<сид>.png`
   (с проектом зелёной): открыть и проверить глазами (зоны, кластеры, ленты, рост).
3. Стадии стройки — **только если пользователь просил** («прогоняй стадии»): скилл
   `stage-runs`.

## Правила

- Решения без «ок» и находки — в `questions.md` (раздел «Открытые», с датой ночи); изменения
  дизайна — сначала в документ (скилл `docs-first`), код — по нему.
- Каждая правка — коммит; правки — Edit, запуск — скриптами (скилл `work-hygiene`).
- Любой запуск игры — с лимитом времени; в конце — все экземпляры остановлены
  (`for i in 0 1 2 3 4; do INST=$i scripts/stop.sh; done`).
- Сломанное по ходу (план не строится, тест падает) — чинить, перепроверить, записать в
  `stages-report.md` («Находки») и `questions.md`.
- В чат — короткие строки по событиям; в конце — отчёт: что сделано, что упало, где картинки,
  какие вопросы.
