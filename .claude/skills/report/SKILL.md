# Отчёт по экземплярам

1. `scripts/report.py` — таблица (только чтение: процессы, `run/iN/map.json`, журналы стадий;
   «игра» — время карты, `game.tick` по RCON).
   В перезапусках ✓ у стадии — упавшая стадия перепрогнана со снимка перед ней на другом
   экземпляре одним запуском и прошла (журнал `run/out/rerun-<сид>-<N>.out`; перепрогон —
   `snapshot.sh load <сид>-(N-1)`, затем `bin/bot -t … stage N` в этот журнал, без снимков и
   журналов прогона). Экземпляр, где лежит снимок карты другого, — «свободен».
2. В чат — таблицу как есть (markdown). Под ней — по строке на каждую упавшую или стоящую:
   причина своими словами и что с ней делается (чиню / жду «ок» / вопрос в `questions.md`).
   Больше ничего.
