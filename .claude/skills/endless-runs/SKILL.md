# Прогон по кругу

Цель (пользователь): стадии 10–68 проходят без вмешательства. Каждая карта — новая, каждая
поломка — починка общим правилом, проверка — со снимка перед стадией.

## Запуск

- Перед запуском — закрыть старое: `for i in 1 2 3 4; do INST=$i scripts/stop.sh; done`.
- Экземпляры 1–3 — по карте, каждый своей командой, в фоне, вывод — `run/out/fullrun-<N>.out`,
  запуск через ~20 с друг от друга:
  `INST=N SHOW=0 EXPLORE=180 LOOP=1 scripts/fullrun.sh`
  (без сида — случайная карта; экземпляр 4 — для тестов и перепрогонов).
- Монитор итогов (30 мин, перезапускать по истечении — один, второй не заводить):
  `tail -n0 -F run/stages/summary.txt run/out/rerun-i4.out | grep --line-buffered -E "fullrun|выполнена за|НЕ выполнена|повтор|не легла|нет снимка|ракета|код [0-9]+"`.
- В чат — строка на событие; таблица — скилл `report`.

## Сам делает `fullrun`

- База не легла (стадия 1 дольше 3 ч или план не встал) — разведка сохраняется (`-1` в
  `run/snapshots/explored`, `run/worlds/<сид>.gob`), новая случайная карта.
- Ракета улетела (`LOOP=1`) — новая случайная карта на том же экземпляре, с начала.
- Стройка упала — повтор на той же игре (`RETRIES`=2); не прошла — стоп, игра остаётся.

## Разведки — для прогонов без игры

Все карты, дошедшие до разведки, остаются: снимок `<сид>-1` в `run/snapshots/explored` и
`run/worlds/<сид>.gob` (решение пользователя) — на них `TestPlan`, `rough`, `estimate`. При уборке
не удалять и не перекладывать. Новая карта — проверить, что оба файла есть.

## Упала стадия (повтор или стоп)

1. Причина — по `run/stages/sN-<сид>.log` и снимку сбоя (`run/iN/debug/`); живая игра — только
   чтение (RCON, мод).
2. Механика — скилл `bug-to-test` (e2e-тест, повторяющий случай; карта, сделанная ботом, —
   копией снимка в `-0`); логика стадии — сразу; дизайн — `docs-first` (без «ок» — в документ и
   `questions.md`). Каждая починка — общее правило, коммит, находка — `stages-report.md`.
3. `fullrun` встал — продолжить на той же игре: `CONT=1 FROM=N INST=k SHOW=0 LOOP=1 EXPLORE=180
   scripts/fullrun.sh <сид>`.
4. Упавшая стадия — перепрогон со снимка перед ней на экземпляре 4 одним запуском (должна
   пройти с первого раза; ✓ в `report`), без снимков и журналов прогона:
   `INST=4 scripts/snapshot.sh load <сид>-(N-1)`, затем
   `INST=4 bash -c "source scripts/inst.sh; run/out/bot4 -t 150m stage N" > run/out/rerun-<сид>-<N>.out`
   (`run/out/bot4` — копия `bin/bot`: сборки прогона её не трогают); итог строкой — в
   `run/out/rerun-i4.out`. Не прошла — снова в п. 1.
5. Итоги — таблица в `stages-report.md` (карта: стадии, ракета, повторы; перепрогоны).

## Нельзя

- `pgrep -f` с шаблоном из своей же команды — находит себя (ждёт вечно); ждать — по файлам или
  `pgrep -x`.
- Код плана (`internal/cluster`, стадия 2) во время прогона не трогать — снимки после стадии 2
  устареют (скилл `stage-runs`).
- Дерево собирается перед каждой стадией — правки без несобираемых промежутков.
